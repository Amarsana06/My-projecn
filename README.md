Проект: Игра Pac-Man на JavaScript

Данный проект представляет собой ремейк классической аркадной игры Pac-Man, полностью реализованный на JavaScript с использованием HTML5 Canvas. Это одностраничное веб-приложение, не требующее установки дополнительных плагинов и работающее прямо в браузере.

Техническая реализация. Игровой мир строится на основе двумерной матрицы (лабиринт), где стены, и пустые клетки кодируются числами. Canvas используется для отрисовки игровых объектов: жёлтого квадрата Pac-Man, четырёх разноцветных призраков (квадратов), точек и лабиринта. Управление осуществляется через клавиши-стрелки.

Геймплей. Игрок избегает встречи с призраками. За каждого съеденного призрака начисляются дополнительные очки, а сам призрак возвращается в центральную клетку. При столкновении с призраком в обычном режиме игрок теряет жизнь и перезапускается на стартовой позиции.

Искусственный интеллект призраков. Ключевая особенность проекта — поведение каждого призрака:
<img width="1262" height="1387" alt="image" src="https://github.com/user-attachments/assets/1c8e9f3f-bc88-447e-aebf-73f38c68d34a" />

· Blinky (красный) всегда выбирает кратчайший путь к текущей позиции игрока.
· Pinky (розовый) целится в точку на несколько клеток впереди Pac-Man с учётом его направления.
· Inky (голубой) использует комбинацию позиции Blinky и вектора движения игрока.
· Clyde (оранжевый) преследует игрока, только пока находится далеко от него; при приближении начинает бродить случайно.

Дополнительный функционал. В проекте присутствуют:
- Система жизней
- Счет

Заключение. Проект демонстрирует работу с Canvas, обработку событий, реализацию волновых алгоритмов поиска пути, управление состоянием игры и хранение данных в браузере. Итог — полностью работоспособная игра Pac-Man, доступная локально через открытие HTML-файла.
