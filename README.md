# My-project
Я хочу сделать игру под названием "Pac-Man" 

Проект: Игра Pac-Man на JavaScript

Данный проект представляет собой ремейк классической аркадной игры Pac-Man, полностью реализованный на JavaScript с использованием HTML5 Canvas. Это одностраничное веб-приложение, не требующее установки дополнительных плагинов и работающее прямо в браузере.

Техническая реализация. Игровой мир строится на основе двумерной матрицы (лабиринт), где стены, точки, энерджайзеры и пустые клетки кодируются числами. Canvas используется для отрисовки игровых объектов: жёлтого Pac-Man, четырёх разноцветных призраков, точек и лабиринта. Управление осуществляется через клавиши-стрелки, события клавиатуры обрабатываются через addEventListener. Движение Pac-Man и призраков происходит по кадрам с помощью requestAnimationFrame — в каждом кадре проверяются коллизии со стенами и обновляются позиции.

Геймплей. Игрок собирает все маленькие точки на уровне, избегая встречи с призраками. По углам лабиринта находятся большие энерджайзеры — после их съедения Pac-Man на несколько секунд получает возможность поедать призраков, за каждого съеденного призрака начисляются дополнительные очки, а сам призрак возвращается в центральную клетку. При столкновении с призраком в обычном режиме игрок теряет жизнь и перезапускается на стартовой позиции.

Искусственный интеллект призраков. Ключевая особенность проекта — поведение каждого призрака:

· Blinky (красный) всегда выбирает кратчайший путь к текущей позиции игрока.
· Pinky (розовый) целится в точку на несколько клеток впереди Pac-Man с учётом его направления.
· Inky (голубой) использует комбинацию позиции Blinky и вектора движения игрока.
· Clyde (оранжевый) преследует игрока, только пока находится далеко от него; при приближении начинает бродить случайно.

Поиск пути реализован волновым алгоритмом BFS (поиск в ширину), который выполняется для каждого призрака каждый кадр или с заданным интервалом для оптимизации производительности.
